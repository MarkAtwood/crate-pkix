## [1.0.0] — TBD

First stable release.

### Added

- RFC 6125 §6.4 hostname-binding implementation (PKIX-fmtv.11.1).
  `ServerName::dns_name` validates LDH + length limits, lower-cases
  ASCII, and converts U-label input to A-label via the `idna` crate.
  `ServerName::ip_address` parses IPv4 dotted-quad and IPv6 (with or
  without brackets) into canonical 4- or 16-byte form; leading zeros,
  out-of-range octets, zone identifiers, and double-`::` runs are
  rejected.
- `verify_dns_name` walks the leaf's Subject Alternative Name
  extension and matches `GeneralName::DnsName` / `GeneralName::IpAddress`
  entries against the target identity. Case-insensitive exact match
  plus single leftmost-label wildcard. `*.<single-label>` (no
  intermediate label) is rejected for structural defense-in-depth.
- RFC 5280 §4.2.1.6 + RFC 8398 mailbox-binding implementation
  (PKIX-fmtv.12.1). `MailboxName::parse` validates RFC 5322 dot-atom
  local-parts (with non-ASCII passed through verbatim per RFC 6532),
  splits on the final `@`, and normalizes the domain to lower-case
  A-label form. `verify_mailbox` walks `Rfc822Name` SAN entries for
  ASCII targets and `OtherName(id-on-SmtpUTF8Mailbox)` SAN entries for
  internationalized targets, decoding the inner `UTF8String` of each
  `OtherName` value. Local-part match is byte-equal; domain match is
  ASCII case-insensitive against the A-label form so a U-label SAN
  and an A-label target (or vice versa) interoperate.
- `IdentityError::MalformedSan` for SAN extensions that fail to parse.
- Integration tests under `tests/verify_dns_name.rs` (18 cases) and
  `tests/verify_mailbox.rs` (17 cases) cover exact / wildcard / IDN /
  IP / mailbox-ASCII / mailbox-SmtpUTF8 / mixed-SAN / missing-SAN /
  CN-only scenarios. Fixtures are generated by `tests/fixtures/gen.py`
  using pyca/cryptography as the independent oracle.
- `idna` (workspace, no_std + `alloc` + `compiled_data`) and `der`
  (workspace) added as runtime deps.

## [0.1.0] — 2026-05-11

### Added

- Initial scaffold (PKIX-fmtv.21). Workspace member; `no_std` (matches
  `pkix-path` discipline); `forbid(unsafe_code)`.
- Public API surface:
  - `ServerName<'a>` with `dns_name` / `ip_address` constructors.
  - `MailboxName<'a>` with `parse` constructor.
  - `IdentityError` enum (`#[non_exhaustive]`).
  - Free functions `verify_dns_name` and `verify_mailbox`.
- All public entry points return `IdentityError::NotYetImplemented`.
  Bodies fill in via PKIX-fmtv.11 (`verify_dns_name`) and
  PKIX-fmtv.12 (`verify_mailbox`).
- Only dep at this stage is `x509-cert` (for the `Certificate`
  signature type). `der` and `idna` are added in PKIX-fmtv.11 / .12
  alongside the bodies that use them.
